About the API

The FAS Academic Data API acts as a centralized read-only data layer for academic schedules, calendars, and structural data. Third-party applications (like AttendTrack) request JSON data directly from this API. The API does not push data into third-party systems.

Read-Only JSON REST No Authentication Required

1. Ingestion Pipeline

Automated GitHub Actions periodically discover, download, and process source PDFs (timetables & calendars) from official FAS channels. The API itself never performs synchronous scraping or OCR parsing during GET requests.

2. Storage & Versioning

Extracted data is strictly validated and stored in Neon PostgreSQL. Source documents are versioned using SHA-256 hashes, ensuring data freshness without storing the raw binary PDFs permanently.

3. Vercel Hosting

The FastAPI application is deployed as Serverless Functions on Vercel. It utilizes connection pooling optimizations (NullPool) to handle highly concurrent read traffic efficiently.

4. Policies

CORS: Enabled for permitted origins.
Rate Limits: None currently enforced.
Data Freshness: Updated automatically via background ingestion workflows.
